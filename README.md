# Cartas ao Padre · instaladores

Instaladores do aplicativo **Cartas ao Padre** para Windows.

**Para instalar:** abra a [versão mais recente](../../releases/latest), baixe o arquivo
`Cartas-ao-Padre-Setup-….exe` e dê dois cliques. Se o Windows mostrar a tela
"O Windows protegeu o computador", clique em **Mais informações** e depois em
**Executar assim mesmo**.

Depois de instalado, o aplicativo procura e instala as versões novas sozinho.

Este repositório guarda só os instaladores. O código é privado.
